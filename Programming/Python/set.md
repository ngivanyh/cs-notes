A `set` is a immutable list which must also only contain unique items, like `tuple`, it can store multiple values of different types. `set`s are also unordered

> Note: `True` and `1` are the same thing in sets, so are `False` and `0`

You declare a set like this:

```python
a = {1, 2, 3}
b = set(DATA) # DATA can be either a list or a tuple

c = set() # empty set
```
