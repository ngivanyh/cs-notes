# maths
`#include <math.h>` first

| Function    | Description     |
| ----------- | --------------- |
| `pow(x, y)` | $x^y$           |
| `sin(x)`    | $\sin x$        |
| `cos(x)`    | $\cos x$        |
| `atan2(x)`  | arctangent      |
| `sqrt(x)`   | $\sqrt{n},n>=0$ |
| `fabs(x)`   | $\|x\|$         |
| `exp(x)`    | $e^x$           |
| `log(x)`    | $\log_e x$      |
| `log10(x)`  | $\log_{10} x$   |
| `log2(x)`   | $\log_2 x$      |

`frand()` for a random number between 0 and 1
`srand()` (unsigned) seed for `rand()`
