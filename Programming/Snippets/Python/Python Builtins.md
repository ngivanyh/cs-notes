# Python Builtins

| Builtin Name              | Type (class method, iterator, function, etc) | Description                                                                                                                |
| ------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `enumerate()`             | Iterator                                     | Returns a tuple of the index and value of a iterator                                                                       |
| `reversed()`              | Iterator                                     | Iterates over a iterator in reverse direction                                                                              |
| `zip()`                   |                                              |                                                                                                                            |
| `sorted()`                | Function                                     | Sorts an iterator, there is an `key=` argument which can specify the key for sorting (what it sorts by) (takes a function) |
| `all()`                   |                                              |                                                                                                                            |
| `map()`                   | Function                                     | Takes two arguments, the first of which is a function will will be applied on the second argument (should be an iterator)  |
| `bin()`, `hex()`, `oct()` | Function                                     | Turns an `int` into a binary, hexadecimal, or octal string.                                                                |
|                           |                                              |                                                                                                                            |
