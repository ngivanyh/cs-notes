# Heap
## Max Heap
1. Is a complete binary tree
2. The value of the root node is the largest
3. The value of the left and right nodes must be the largest of its subtree

## Min Heap
1. Is a complete binary tree
2. The value of the root node is the smallest
3. The value of the left and right nodes must be the smallest of its subtree
